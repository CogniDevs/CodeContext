# CodeContext

**CodeContext** — это высокопроизводительный инструмент для мгновенного сканирования, анализа и упаковки кодовой базы в структурированный контекст (XML или TXT), оптимизированный для работы с большими языковыми моделями (LLM: GPT-4o, Claude 3.5/3.7, DeepSeek, Qwen и др.).

Программа решает проблему ручного сбора контекста: интеллектуально сокращает объём передаваемых данных (экономя до 98% токенов через режим Git Diff и скелетонизацию), отсекает мусорные файлы и автоматически обогащает контекст системными инструкциями, стандартами разработки и ролями экспертов.

---

## 🏛️ Архитектура системы (Dual-Mode Engine)

Приложение спроектировано как единый SPA-интерфейс с поддержкой двух режимов исполнения:

1. **Desktop-режим (FastAPI + PyWebView + Rust PyO3):**
   * **Бэкенд:** Python 3.11+ на базе асинхронного FastAPI и Uvicorn.
   * **GUI:** Легковесное нативное окно PyWebView.
   * **Ядро:** Нативная библиотека Rust (`codecontext_core`), скомпилированная через C-ABI (PyO3). Обеспечивает прямой доступ к файловой системе ОС, интеграцию с Git CLI и потоковое слежение за файлами через Server-Sent Events (SSE + Watchdog).

2. **WebAssembly-режим (Serverless Web / GitHub Pages):**
   * **Ядро:** Rust (`codecontext_core`), скомпилированный в WebAssembly через `wasm-pack` и `wasm-bindgen`.
   * **Автономность:** Все операции (токенизация, очистка комментариев, маскирование секретов, скелетонизация и трассировка импортов) выполняются **на 100% локально в браузере клиента**. Исходный код проекта никогда не покидает ваше устройство.
   * **Доступ к файлам:** Браузерные API (File System Access API и Drag-and-Drop WebKit Directory Reader).

3. **Frontend (Angular 22 + TypeScript 6.0 + Signals):**
   * Полностью реактивная архитектура на базе Angular Signals (`signal`, `computed`, `input`, `output`, `viewChild`).
   * Стабильный режим без Zone.js (`provideZonelessChangeDetection`) со стратегией `ChangeDetectionStrategy.OnPush`.
   * Модульное разделение ответственности по принципам Clean Architecture / Domain-Driven Design: `@layouts/*`, `@view/*`, `@shared/*`, `@core/*`, `@models/*`.

## ✨ Ключевые возможности

### ⚡ Сверхбыстрое сканирование диска
Благодаря многопоточному сканеру на Rust и интеграции с крейтом `ignore`, система за миллисекунды индексирует проекты из сотен тысяч файлов, выстраивает актуальное ASCII-дерево и производит точный подсчёт BPE-токенов (`cl100k_base` через `tiktoken-rs`).

### 🧬 Режим Delta Context (Git Diff)
Позволяет экономить до 98% токенов при ревью и итеративной разработке. Вместо отправки всего исходного кода отправляется сжатый патч реальных изменений репозитория (`git diff -U3`) с настраиваемым контекстом строк.

### 🧠 Smart Token Budgeting (Контроль лимитов)
Автоматическая двухуровневая укладка контекста в заданный лимит (32k, 64k, 128k, 200k токенов):
1. Если контекст превышает лимит, ядро переводит функции и методы в режим сигнатур (скелетонизация).
2. Если лимит всё ещё превышен, система выполняет умное усечение (Smart Truncation) самых крупных файлов.

### 🔌 Интеллектуальная трассировка импортов (Dependency Tracer)
Автоматически находит и выделяет всю цепочку связанных локальных файлов для указанной точки входа:
* **Python:** Многострочные `import`, `from ... import`, относительные пакетные импорты.
* **JavaScript / TypeScript:** ES6 `import`, динамические `import(...)`, вызовы `require(...)`.
* **C / C++:** Директивы `#include` локальных заголовков.
* **Rust:** Модули `mod` и цепочки `use crate::`, `use super::`, `use self::`.

### 💀 Скелетонизация кода (Сигнатурный режим)
Вырезает тела функций и методов, оставляя только сигнатуры и интерфейсы:
* Для C-подобных языков (C, C++, Rust, TS/JS, Go, Java, C#, Swift, Kotlin): побайтовый конечный автомат скобок в Rust.
* Для Python: сохранение docstring классов и функций с заменой тел на `...`.

### 🧼 Очистка комментариев и сжатие пробелов
Удаляет однострочные и многострочные комментарии, сохраняя защищённые строковые литералы (включая обратные кавычки `` `...` `` в JS/TS). Сжимает избыточные пустые строки.

### 🔒 Автоматическое маскирование секретов
Находит и заменяет на заглушки API-ключи (OpenAI, Anthropic, AWS, Google, Stripe, GitHub и др.), JWT-токены, приватные ключи (`-----BEGIN PRIVATE KEY-----`), пароли в конфигах и строки подключения к БД.

### 🎛️ Интерактивный .gitignore
Считывает файл `.gitignore` вашего проекта и визуализирует его правила в виде интерактивных баджей в настройках. Вы можете принудительно отключать или включать отдельные правила прямо в UI.

### 🎯 Конструктор системных скиллов ИИ
Позволяет создавать кастомные профили инструкций с разбиением на структурированные XML-блоки:
* **Роль эксперта (`<expert_role>`):** Определение профессиональной модели поведения.
* **Протокол диалога (`<interaction_protocol>`):** Запрет на преждевременный вывод кода до согласования архитектурного плана.
* **Стандарты качества (`<code_generation_standards>`):** Запрет на плейсхолдеры (`// TODO`, `// остальной код`).
* **Синхронизация версий (`<technology_alignment>`):** Обязательство ИИ писать код под версии библиотек из манифестов проекта.

### 3. Запуск из исходного кода для разработки

#### Требования:
* **Python** 3.11+
* **Rust** (Cargo toolchain) + `wasm-pack`
* **Node.js** 22+ & **npm**

#### Быстрый старт (Windows):
Запустите скрипт в корне репозитория:
```cmd
run.bat
```
Скрипт автоматически создаст виртуальное окружение Python, скомпилирует C-ABI ядро Rust, соберет WebAssembly и запустит десктопное приложение.

#### Ручная сборка и запуск:
1. **Сборка нативного ядра Rust (C-ABI для Python):**
   ```bash
   cd codecontext_core
   cargo build --release --features python
   # Скопируйте скомпилированную библиотеку в backend/ (codecontext_core.pyd или .so)
   cd ..
   ```

2. **Сборка WebAssembly и Frontend:**
   ```bash
   cd frontend
   npm install
   npm run build
   cd ..
   ```

3. **Запуск сервера и десктопного окна:**
   ```bash
   python -m pip install -r requirements.txt
   python main.py
   ```
