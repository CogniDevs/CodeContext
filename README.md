# CodeContext

CodeContext — это высокопроизводительное приложение для мгновенного сканирования, анализа и упаковки исходного кода проектов в структурированный контекст (XML или TXT), оптимизированный для работы с большими языковыми моделями (LLM: GPT, Claude, DeepSeek и др.).

Программа решает проблему ручного копирования кода, интеллектуально сокращая объем передаваемых данных (экономя токены) и автоматически обогащая контекст правилами взаимодействия, ролями и стандартами разработки.

---

## Архитектура проекта

Инструмент построен на базе гибридной архитектуры:
* **Высокопроизводительное ядро (Rust Engine):** Выполняет тяжелые операции сканирования диска, побайтового лексического анализа, токенизации (Tiktoken `cl100k_base`), маскирования и обработки текста.
* **Настольный интерфейс (PyQt6):** Удобный и отзывчивый GUI-клиент, взаимодействующий с Rust-ядром через нативные биндинги PyO3.
* **Веб-версия (Angular + WebAssembly):** *В процессе разработки.* Концепция веб-приложения на фреймворке Angular. Благодаря компиляции Rust-ядра в WebAssembly (WASM), веб-версия будет выполнять все операции по анализу проекта, очистке комментариев, скелетонизации и трассировке импортов прямо внутри браузера на стороне клиента. Исходный код вашего проекта никогда не отправляется на сервер, гарантируя полную конфиденциальность.

## Возможности и функции

### ⚡ Сверхбыстрое сканирование и обработка
Благодаря многопоточному сканеру на Rust, приложение мгновенно индексирует репозитории любого масштаба, выстраивает актуальное ASCII-дерево проекта и рассчитывает точное количество токенов в реальном времени.

### 🔌 Интеллектуальная трассировка импортов (Dependency Tracing)
Вам больше не нужно вручную искать файлы, связанные с вашей задачей. Укажите ключевой файл, и система автоматически найдет и выделит всю цепочку локальных зависимостей и импортов для следующих языков:
* **Python:** Разбор многострочных инструкций `import` и `from ... import`, относительных импортов с точками и пакетов.
* **JavaScript / TypeScript:** Поддержка ES6-импортов, динамических `import(...)` и вызовов `require(...)`.
* **C / C++:** Парсинг локальных директив `#include`.
* **Rust:** Анализ вложенных модулей `mod` и цепочек `use crate::`, `use super::`, `use self::`.

### 💀 Умное сжатие кода (Скелетонизация / Сигнатурный режим)
Для экономии контекстного окна LLM вы можете перевести выбранные файлы в режим сигнатур. 
* Для C-подобных языков специальный конечный автомат Rust аккуратно вырезает тела функций и методов, оставляя лишь сигнатуры и интерфейсы `{ ... }`.
* Для Python используется AST-парсер, сохраняющий сигнатуры методов, docstrings классов и заменяющий тела функций на многоточия.

### 🧼 Глубокая очистка и удаление комментариев
Интеллектуальный стриппер на базе регулярных выражений и правил синтаксиса удаляет однострочные и многострочные комментарии, а также лишние переносы строк и пробелы. Стриппер полностью безопасен для JS/TS, так как игнорирует символы `//` и `/*` внутри шаблонных строк (обратных кавычек).

### 🔒 Автоматическое маскирование секретов
Встроенный валидатор на лету находит и заменяет на заглушки конфиденциальные данные перед копированием: API-ключи (OpenAI, Anthropic, Google, AWS и др.), JWT-токены, приватные ключи и строки подключения к базам данных.

### 📂 Интеграция с Git и .gitignore
* **Режим «Только Git»:** Возможность автоматически выделить в дереве экспорта только измененные и новые файлы на основе статуса вашего локального репозитория.
* **Интерактивный .gitignore:** Программа считывает файл `.gitignore` вашего проекта и строит список правил в виде интерактивных баджей. Вы можете гибко включать или принудительно отключать отдельные правила игнорирования прямо из интерфейса.

### 👁️ Автоматическое слежение (File Watcher)
Интегрированный наблюдатель файловой системы автоматически фиксирует изменения файлов на диске и обновляет структуру проекта, статистику токенов и финальный буфер в фоновом режиме, не блокируя работу пользователя.

### 🧠 Конструктор системных скиллов для ИИ
Вы можете создавать индивидуальные профили (скиллы) для ИИ. Программа компилирует системные инструкции, разбивая их на структурированные XML-блоки:
* **Роль эксперта:** Определение профессиональной идентичности ИИ (Архитектор, Специалист по ИБ и т.д.).
* **Протокол диалога:** Обязательные требования к этапам работы (например, запрет на вывод кода до согласования архитектурного плана).
* **Стандарты качества:** Запреты на использование заглушек вида `// остальной код без изменений`, требования к полноте реализации.
* **Синхронизация версий:** Обязательство ИИ прочитать манифесты зависимостей вашего проекта и использовать API строго тех версий библиотек, которые установлены у вас.
